# 🍔 FoodCampus — Лабораторная работа №3

## Реализация модуля CartModule по User Story

**User Story:** Как студент, я хочу добавлять блюда в корзину и применять промокод для скидки.

**Модуль:** CartModule  
**Метод:** `calculate_total(items_prices, promo_code)`

## 🐛 Bug Report

| ID | Модуль и метод | Входные данные | Ожидаемый результат | Фактический результат |
|----|----------------|----------------|---------------------|----------------------|
| BUG-01 | CartModule.calculate_total | `[-500, 100]` | Игнорирование отрицательной цены или ошибка валидации | Программа вернула отрицательную сумму или 0.0, не сообщив об ошибке |
| BUG-02 | CartModule.calculate_total | `["abc", 100]` | Сообщение "Некорректный формат цены" | Программа упала с `TypeError: unsupported operand type(s) for +: 'int' and 'str'` |
| BUG-03 | CartModule.calculate_total | `None` | Возврат 0.0 | Программа упала с `TypeError: 'NoneType' object is not iterable` |
